# 2026-10-15 環境構築(工程1)

## イメージのダウンロードが途中で止まったように見えた
- 症状: `docker pull` / `docker run` をバックグラウンド実行すると、出力が途中で途切れ「終了」と表示されるが、イメージが一覧に出ない
- 実際: ダウンロードは裏で続いていた。展開まで含めて約20分かかった
- 確認方法: Docker の仮想ディスク `%LOCALAPPDATA%\Docker\wsl\disk\docker_data.vhdx` のサイズが増えているかを見る
- 教訓: 大きなイメージは時間がかかる。慌てて再実行しない

## 起動確認
- コンテナ `pai_ros2` 起動。ポート 6080(ブラウザ)/9090/9876 公開
- http://localhost:6080/ が HTTP 200 を返す
- 共有フォルダ: Windows `work/` ⇔ コンテナ `/home/ubuntu/work` で読み書きできる
- `docker exec` は既定で root として実行される(`~` が /root になる)。講義のパス(~/pai_ws など)を使うときは `-u ubuntu` を付ける

## 画面録画
- 方法: コンテナ内の ffmpeg で X11 画面 :0 を直接録画(`record.ps1`)。Ubuntuデスクトップだけが映り、Windows側は映らない
- 解像度 2400x1288、15fps。保存先は video\(GitHubに上げない)
- 録画中は CPU 負荷で RTF が下がる(試し録画中に 0.39 を観測)。本番動画は2倍速の利用も検討

## 画面ロックでパスワードが分からなくなった(10/15 夜)
- 原因: Ubuntu デスクトップの mate-screensaver が一定時間でロックする
- 解除と無効化(Windows 側から):
  docker exec -u ubuntu pai_ros2 bash -c "export $(tr '\0' '\n' < /proc/$(pgrep -u ubuntu -x mate-screensave | head -1)/environ | grep -E '^(DISPLAY|DBUS_SESSION_BUS_ADDRESS)=' | xargs); mate-screensaver-command -d; gsettings set org.mate.screensaver lock-enabled false; gsettings set org.mate.screensaver idle-activation-enabled false"
